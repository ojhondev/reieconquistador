# Rei e Conquistador (remake)

Reconstrução/homenagem a um MMO de estratégia em navegador brasileiro dos anos
2010, hoje fora do ar e sem sucessor oficial. Documentação de design em
[`docs/GDD.md`](docs/GDD.md).

Nome, arte e conteúdo do jogo original **não** são reaproveitados — este projeto
reconstrói os sistemas de jogo (economia, construção, herói, combate, guildas) a
partir de pesquisa pública, como ponto de partida para um design próprio.

## Status

Fase de design (GDD). Nenhum código de jogo ainda.
